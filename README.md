# D-MAP iOS 智能手表伴侣 App

为 smartmovt 方案的无屏显智能手表编写的 iOS 原生 App，基于从 Android 版 D-MAP (V1.0.36) 逆向提取的 BLE 协议实现。

## 功能

- 蓝牙连接手表（扫描、连接、状态显示、电量/固件版本读取）
- 时间同步（连接后自动同步，也可手动同步）
- 闹钟管理（最多 5 个，支持重复日期设置）
- 久坐提醒（可设置间隔、时段、休息时长）
- 通知同步（来电、短信、微信、QQ、其他应用推送到手表）
- 遥控拍照（进入拍照模式后，手表按键触发手机拍照，自动保存到相册）
- 查找手表（让手表震动响铃）

## 系统要求

- iOS 15.0+
- Xcode 15.0+
- iPhone（支持蓝牙 4.0+）

## 编译安装步骤

### 1. 准备环境

需要一台 Mac 电脑，安装 Xcode 15 或更高版本。

### 2. 打开项目

```bash
# 进入项目目录
cd D-MAP-iOS

# 用 Xcode 打开
open D-MAP-iOS.xcodeproj
```

### 3. 配置签名

1. 在 Xcode 左侧选中项目根节点 `D-MAP-iOS`
2. 选择 TARGETS → `D-MAP`
3. 进入 `Signing & Capabilities` 标签页
4. 勾选 `Automatically manage signing`
5. 选择你的 Apple ID 对应的 Team
6. 修改 `Bundle Identifier` 为你自己的标识（如 `com.yourname.dmap`）

### 4. 编译运行

1. 用数据线连接 iPhone 到 Mac
2. 在 Xcode 顶部选择你的 iPhone 作为运行目标
3. 按 `Cmd + R` 编译并安装到手机
4. 首次运行需要在 iPhone 上信任开发者证书：
   - 设置 → 通用 → VPN与设备管理 → 信任你的 Apple ID

### 5. 授权权限

首次打开 App 时，系统会请求以下权限，请全部允许：
- 蓝牙权限（连接手表必需）
- 相机权限（遥控拍照必需）
- 相册权限（保存照片必需）
- 通知权限（通知同步相关）

## 使用说明

### 连接手表

1. 打开 App，进入「设备」标签页
2. 确保手表已开机且处于可配对状态
3. 点击「扫描设备」
4. 在列表中找到你的手表，点击连接
5. 连接成功后自动同步时间和设置

### 设置闹钟

1. 进入「闹钟」标签页
2. 点击右上角 `+` 添加闹钟
3. 设置时间、重复日期
4. 保存后自动同步到手表
5. 最多支持 5 个闹钟

### 久坐提醒

1. 进入「设置」→「久坐提醒」
2. 开启久坐提醒
3. 设置提醒间隔（30-180分钟）、提醒时段、休息时长
4. 设置自动同步到手表

### 遥控拍照

1. 进入「拍照」标签页
2. 确保手表已连接
3. 点击「进入拍照模式」
4. 按手表上的按键即可触发手机拍照
5. 照片自动保存到相册
6. 用完后点击左上角 `×` 退出拍照模式

### 通知同步

1. 进入「设置」→「通知同步」
2. 开启需要推送到手表的应用类型
3. 可点击「发送测试通知到手表」验证

## iOS 平台限制说明

由于 iOS 系统的安全限制，以下功能与 Android 版存在差异：

### 短信同步
- **Android**：可直接读取短信数据库，推送短信内容到手表
- **iOS**：不允许第三方应用读取短信内容。仅能在收到短信时通过系统通知有限转发，无法读取短信正文内容

### 通知同步
- iOS 不允许第三方应用读取其他应用的通知内容
- 本 App 的通知推送为主动触发模式（如来电时通过 CoreTelephony 检测），无法像 Android 那样自动转发所有应用通知
- 如需完整通知转发，需用户在系统设置中为对应应用开启通知权限

### 后台运行
- iOS 对后台蓝牙连接有严格限制
- App 在后台时可能被系统挂起，导致手表断开连接
- 建议将 App 保持在前台使用，或添加到常用 App

### 短信内容读取
- iOS 完全禁止第三方应用访问短信数据库
- 这是系统级限制，无法通过任何方式绕过

## BLE 协议说明

协议帧格式（从 Android 源码逆向提取）：

```
[0x24][len][0x02][cmd][paramLen][params...][checksum]
```

- `0x24`：帧头
- `len`：数据长度（从 byte[2] 到校验前）
- `0x02`：固定命令类型
- `cmd`：子命令
- `paramLen`：参数长度
- `params`：参数数据
- `checksum`：校验和 = sum(byte[3..<n-1]) & 0xFF

### 主要命令字

| 功能 | cmd | 说明 |
|------|-----|------|
| 时间同步 | 0x04 | 年月日时分秒+星期 |
| 闹钟设置 | 0x09 | 时分/重复掩码/序号/开关 |
| 久坐提醒 | 0x0A | 开关+间隔分钟 |
| 通知推送 | 0x02 | 未读/已读+类型 |
| 拍照模式 | 0x03 | sub=0x02，进入/退出 |
| 版本电量 | 0x0C | 查询固件版本和电量 |

### UUID

- 主服务：`0000a800-0000-1000-8000-00805f9b34fb`
- 写命令特征：`0000a801-0000-1000-8000-00805f9b34fb`
- 写数据特征：`0000a802-0000-1000-8000-00805f9b34fb`
- 通知特征：`0000a803-0000-1000-8000-00805f9b34fb`
- 电量服务：`0000180f-...`，特征 `00002a19-...`
- 设备信息：`0000180a-...`，固件特征 `00002a26-...`

## 常见问题

### Q: 扫描不到手表？
A: 确保手表已开机、电量充足，且未被其他设备连接。部分手表需要长按按键进入配对模式。

### Q: 连接后自动断开？
A: iOS 后台限制可能导致断开。尝试将 App 保持在前台，或在设置中关闭低电量模式。

### Q: 遥控拍照没反应？
A: 确保已进入拍照模式（相机预览已显示），且手表按键功能正常。部分手表需要在设置中开启拍照触发功能。

### Q: 闹钟不同步？
A: 确保手表已连接，修改闹钟后会自动同步。可在设备页面点击「同步时间」验证连接是否正常。
